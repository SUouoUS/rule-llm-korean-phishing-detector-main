# 문자 사기 확인 (웹앱)

받은 문자가 사기 문자인지 확인하고, 위험한 부분을 쉬운 말로 알려 주는 웹 화면입니다.
노약자·디지털 취약자가 혼자서도 쓸 수 있게 만들었습니다.

탐지 로직은 새로 만들지 않고 이 저장소의 기존 코드를 그대로 불러서 씁니다.

| 쓰는 것 | 어디서 |
|---|---|
| Rule 점수 | `evaluation/evaluate_rule_thresholds.py` 의 `predict_score` |
| Rule 신호 | `rule_engine/detector.py` 의 `analyze_message` |
| 임계값 | `hybrid/detector.py` 의 `RULE_THRESHOLD` |
| LLM | `llm/detector.py` 의 `detect_with_llm` |

Rule 설정은 `webapp/rules_setup.py`에서 CLAUDE.md의 확정 사항(`enum+general`)대로
고정합니다. 택배사 공식 도메인 허용과 "접수제한" 예외도 함께 켭니다.

## 설치 (Windows PowerShell)

프로젝트 루트에서 실행하세요.

```powershell
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

캡처 사진에서 글자를 읽는 기능을 쓰려면 하나 더 설치합니다. **용량이 큽니다**
(torch까지 약 250MB).

```powershell
pip install easyocr
```

설치하지 않아도 웹앱은 정상 동작합니다. 사진 올리기만 막히고, 문자를 붙여 넣는
확인은 그대로 됩니다.

> **첫 실행 때 한 번 다운로드가 있습니다.** EasyOCR은 처음 사진을 읽을 때 한국어
> 글자 모델(약 100MB)을 인터넷에서 받아 옵니다. 한 번 받은 뒤에는 이 PC 안에서만
> 돌아갑니다. 시연 영상을 찍을 때는 **미리 사진 한 장을 올려 모델을 받아 둔 뒤**
> 녹화하세요.

## 실행

```powershell
.\.venv\Scripts\Activate.ps1
python -m uvicorn webapp.main:app --reload
```

브라우저에서 `http://127.0.0.1:8000` 을 엽니다.

3단계(한 번 더 확인)를 쓰려면 Ollama가 켜져 있어야 합니다(`qwen3:1.7b`).
꺼져 있으면 3단계를 건너뛰고 "추가 확인을 하지 못했어요"라고 알립니다.

## 확인 순서

1. **예시 단추**로 네 가지를 먼저 보세요.
   - 평범한 문자 → 위험 신호 없음
   - 택배 알림 → 주소가 있어도 위험 신호 없음 (공식 도메인 허용이 동작하는지 확인)
   - 문자 사기 → 위험
   - 애매한 문자 → Rule은 0점, 3단계로 넘어감
2. **글씨 크기** 보통 / 크게 / 아주 크게를 눌러 보고, 새로 고침해도 유지되는지 보세요.
3. **고대비**를 켜 보세요.
4. **키보드만으로** Tab과 Enter로 처음부터 끝까지 되는지 보세요.
5. **휴대폰 화면 크기**(브라우저 창을 좁게)에서 깨지지 않는지 보세요.
6. 사진 올리기 → 읽은 글자 고치기 → 검사하기 순서를 확인하세요.

## 판정이 실험과 같은지 확인

```powershell
python -m webapp.verify_against_test
```

웹앱의 Rule 설정으로 Test 2,383건을 돌려서, Test 최종 평가의 final 결과와 숫자가
같은지 맞춰 봅니다(놓친 스미싱 70건, 오탐 12건). LLM을 쓰지 않아 몇 초면 끝납니다.

## 개인정보

- 모든 처리는 이 PC 안에서 합니다. 외부 API를 호출하지 않습니다.
- 넣은 문자와 올린 사진은 메모리에서만 다루고 파일로 저장하지 않습니다.
- 서버 로그에 문자 내용을 적지 않습니다.

## 화면에서 지키는 원칙

- "안전합니다", "정상입니다"처럼 안전을 보장하는 말은 쓰지 않습니다.
  위험 신호가 없을 때도 "뚜렷한 위험 신호를 찾지 못했어요"라고만 말합니다.
- 설명의 근거는 Rule이 실제로 찾은 표현만 씁니다. LLM이 내놓는 이유는 프롬프트의
  문구를 그대로 복창하는 경향이 있어 화면에 쓰지 않습니다.
- '주의' 단계는 걸린 표현이 없으므로 "특정 표현은 없지만 문맥상 의심스러워요"라고만
  말하고 근거를 지어내지 않습니다.
- 색만으로 구분하지 않고 글자와 아이콘을 함께 씁니다.

## 전화번호 출처

`webapp/actions.py` 주석에 번호별 공식 출처와 확인일을 적어 두었습니다.
공식 기관 사이트에서 확인하지 못한 번호는 넣지 않았습니다. 은행 지급정지 번호는
은행마다 달라 "통장이나 카드에 적힌 고객센터"로 안내합니다.
